# X Space Recorder

X SpaceのURLを貼るだけで音声を保存できるWindowsアプリです。進行中のSpaceは、アプリ起動前の音声を取得してからライブ音声を追加します。終了済みでも、公開リプレイが残っていれば保存できます。

> [!IMPORTANT]
> 録音・保存する権限があるSpaceでのみ使用してください。参加者のプライバシー、著作権、Xの利用規約、地域の法令を確認してください。

## ダウンロードして使う

1. [GitHubのReleases](https://github.com/posobiak-star/x-space-recorder/releases/latest) から `X-Space-Recorder-1.3.1-Windows.zip` をダウンロードします。
2. ZIPを右クリックし、**すべて展開**します。
3. `X Space Recorder.exe` を起動します。
4. 初回だけ、画面の **FFmpegを導入** を押します。
5. SpaceのURLを貼り、**録音開始**を押します。

本アプリはコード署名を行っていないため、Windows SmartScreenの警告が出る場合があります。配布元とダウンロード場所を確認して使用してください。

## 主な機能

- ライブ開始時点から現在までの音声を遡って取得
- 取得後もSpace終了まで新しい音声を継続追加
- 終了済みSpaceの公開リプレイを保存
- Spaceタイトルをファイル名に使用
- 同名ファイルを上書きせず連番で保存
- 配信中は5秒ごとに完全履歴を再確認し、スリープや一時切断で欠けたチャンクをその場で自動補完
- Space終了時にも最終補完を実行
- 録音中はWindowsの自動スリープを抑止
- ライブ側の終了印からSpace終了を検知
- 30秒間チャンクが進まない場合はSpace状態を再確認し、進行中・終了後リプレイあり・録音なしを判別
- 「録音停止」は新規取得と補完を打ち切り、取得済みチャンクをすぐ保存
- Source / M4A / MP3 / WAV / Opusに対応
- 認証なし、またはログイン済みブラウザのCookieを使用
- 取得中・ライブ録音・補完・保存の状態と、取得済み音声時間・データ量・処理時間を表示
- ライト／ダークモードを切り替え可能
- 保存先・形式・ログイン方式・表示モードを次回起動時にも記憶
- 保存後にアプリから音声を再生、またはエクスプローラーでファイルを表示
- 一時的に履歴が読めなくてもライブ取得を続け、過去音声を再試行

### 画面の操作

URL欄の「貼り付け」または `Ctrl+V` でURLを入力し、Enterキーでも録音を開始できます。
設定欄は普段は折りたたまれ、形式・ログイン方式・保存先の要約を1行で表示します。「録音設定を表示」で確認や変更ができます。
音声時間やデータ量は録音を始めると表示します。実行ログも普段は閉じていて、「ログを表示」で開けます。エラーや警告が出ると自動で開きます。
小さい画面では右端のスクロールバーで画面全体をスクロールできます。
画面上部の「ダークモード」で配色を切り替えられます。録音中でも変更できます。

音声時間は取得済みチャンクの長さの合計で、アプリの処理時間とは異なります。
過去音声の取得中は取り込みの進み具合をバーで表示し、ライブ中と保存中は動くバーを表示します。
ログを読み返している間は自動スクロールを止めます。「ログをコピー」で問い合わせ用にコピーできます。

## 保存先

- DドライブがあるPC：`D:\X Space Recorder`
- DドライブがないPC：`ミュージック\X Space Recorder`

アプリ画面から保存先を変更したり、保存フォルダを直接開いたりできます。

保存ファイル名にはSpace名を使用します。同名ファイルがある場合は上書きせず、`Space名 (2).m4a` のように連番を付けます。

## ソースからビルドする

ビルドしてデスクトップへインストールするには次を実行します。

```powershell
.\build-app.ps1 -Install
```

### 保存形式の違い

| 形式 | 特徴 | おすすめ用途 |
| --- | --- | --- |
| Source（推奨・M4A） | Xの元のAAC音声を再エンコードせずM4Aに格納します。音質劣化がなく、保存処理も最速です。 | 通常はこれを選んでください |
| M4A | 現在の実装ではSourceと同じ処理です。 | Sourceと同じ |
| MP3 | 多くの機器やソフトで再生できます。変換時間がかかり、再エンコードによるわずかな音質劣化があります。 | 幅広い環境で共有・再生する場合 |
| WAV | 無圧縮のため編集しやすい一方、容量が非常に大きくなります。元音声より高音質になるわけではありません。 | 音声編集ソフトへ渡す場合 |
| Opus | 小容量で高音質ですが、対応していない再生・編集ソフトがあります。 | 容量を抑えて保管する場合 |

迷った場合は `Source（推奨・M4A）` を選択してください。

### ログイン設定の違い

| 設定 | 内容 |
| --- | --- |
| 認証なし（推奨） | Xへログインせずに取得します。公開Spaceでは、まずこちらを試してください。 |
| Firefox | FirefoxでXにログイン済みの場合、そのCookieを利用します。ログインが必要なSpaceや、認証なしでは取得できない場合に使用します。 |

アプリへXのIDやパスワードを入力する必要はありません。ブラウザCookieはローカルの `yt-dlp` が読み取り、Xへの取得リクエストにのみ使用します。本アプリがCookieを独自に保存したり、第三者へ送信したりすることはありません。

Firefoxが入っていない場合は、画面に **Firefoxをダウンロード** ボタンが表示されます。ボタンはMozilla公式ページを開くだけで、Firefoxを勝手にインストールすることはありません。インストール後はFirefoxでXへログインし、Firefoxを完全に終了してから録音を開始してください。

Chrome・Edge・Braveは、WindowsのCookie暗号化仕様によってログイン情報を読み取れない場合があるため、通常画面の選択肢には表示していません。

### 欠損の自動補完ログ

配信中に未保存チャンクを検知すると、次のように表示してその場で回収します。

```text
欠落を検知: 8チャンクを自動補完します…
自動補完完了: 8チャンクを回収しました
```

すぐに回収できないチャンクは、Spaceが続いている間5秒ごとに再試行します。Space終了時には、完全履歴をもう一度確認して「最終補完」を行います。履歴をすぐに読めない場合や未取得のチャンクが残る場合は、5秒おきに最大4回まで試します。手動停止では待ち時間を避けるため、最終補完を省略して取得済み分を保存します。

再試行しても取得できないチャンクがある場合は警告を表示し、取得済みの音声を保存します。欠落部分は無音で埋めず、前後の音声をつなぎます。

同じ欠損が残っているだけのときは、補完待ちのログを繰り返し表示しません。新しく到着した音声も欠損扱いにはしません。

### 録音停止とSpace終了の検知

「録音停止」を押すと、新しいチャンク取得と補完を打ち切り、取得済み分の結合・保存へ進みます。手動停止では待ち時間を避けるため最終補完を省略します。

画面の停止ボタンは「停止して保存」と表示されます。通信中のリクエストは最大10秒程度待つことがあり、結合・形式変換にも時間がかかります。
音声を取得する前に停止した場合は「録音を中止しました」と表示し、空の音声ファイルは作りません。

Space終了はライブプレイリストの終了印から検知し、その時点で最終補完を開始します。履歴プレイリストには配信中でも終了印が付くため、終了の判断には使いません。

終了印が付かない場合に備え、チャンク番号が30秒間進まないと元のSpace情報を再確認します。`is_live`ならライブ取得を継続し、`was_live`または`post_live`なら終了します。公開リプレイがあれば最終補完し、録音が残されていなければ取得済み分だけを保存します。時間経過だけでは終了せず、Xが返したSpace状態を確認して判断します。

### CLIのセットアップ

PowerShellでこのフォルダへ移動し、`yt-dlp` とFFmpegを導入します。

```powershell
.\setup.ps1 -InstallFfmpeg
```

すでにFFmpegがPATHに入っている場合だけ、スイッチを省略できます。

```powershell
.\setup.ps1
```

PowerShellの実行ポリシーで止まる場合は、その1回だけ次の形式で実行できます。

```powershell
powershell -ExecutionPolicy Bypass -File .\setup.ps1
```

### CLIで録音

まず認証なしで試せます。

```powershell
.\record.ps1 "https://x.com/i/spaces/SPACE_ID"
```

Xへのログインを要求された場合は、ログイン済みブラウザを指定します。

```powershell
.\record.ps1 "https://x.com/i/spaces/SPACE_ID" --browser firefox
```

FirefoxのCookieは `yt-dlp` がローカルで読み取り、このツールが保存・第三者へ送信することはありません。読み取りに失敗する場合はFirefoxを完全に終了して再試行してください。

既定では元ストリームの形式を保ち、`recordings` に保存します。X SpaceのHLS取得にはFFmpegが必要です。MP3へ変換する例:

```powershell
.\record.ps1 "https://x.com/i/spaces/SPACE_ID" --browser firefox --format mp3
```

保存先を変える例:

```powershell
.\record.ps1 "https://x.com/i/spaces/SPACE_ID" -o "D:\Space録音"
```

停止は `Ctrl+C` です。通信切断時は自動的に再試行します。X側の仕様変更に追従するには、時々 `setup.ps1` を再実行して `yt-dlp` を更新してください。

## 注意

- ブラウザから聴取できる進行中Space、または公開リプレイのある終了済みSpaceが対象です。
- ホストが録音を残さないSpaceは、終了後に取得できなくなる場合があります。
- PCのふたを閉じた際のスリープは抑止できない場合があります。スリープ中は録音・補完処理も停止するため、録音中はPCのふたを閉じないでください。
- X公式APIはSpaceの情報参照には使えますが、音声ストリーム自体は返しません。本ツールではAPIキーは不要です。
- 録音について参加者への告知、プライバシー、著作権、利用規約、地域の法令を確認し、録音・保存する権限がある場合だけ使用してください。
- Xの仕様変更により一時的に取得できなくなる場合があります。配布版は新しいリリースへ更新してください。ソース版は `setup.ps1` を再実行してyt-dlpを更新できます。

## プライバシー

本アプリには広告、アクセス解析、利用状況送信、開発者が運営するサーバーはありません。録音データは選択した保存先にだけ保存されます。詳細は [SECURITY.md](SECURITY.md) を参照してください。

画面設定は `%LOCALAPPDATA%\X Space Recorder\settings.json` に保存します。内容は保存先・形式・ログイン方式・表示モードのみで、SpaceのURL・Cookie・パスワードは含みません。
変換が完了した時点で完成ファイルを保存先に置きます。取得や変換に失敗した場合は、取得済みチャンクを一時フォルダに残し、画面からその場所を開けます。
