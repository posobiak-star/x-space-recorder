# X Space Recorder

X SpaceのURLを貼るだけで音声を保存できるWindowsアプリです。進行中のSpaceは、アプリ起動前の音声を取得してからライブ音声を追加します。終了済みでも、公開リプレイが残っていれば保存できます。

> [!IMPORTANT]
> 録音・保存する権限があるSpaceでのみ使用してください。参加者のプライバシー、著作権、Xの利用規約、地域の法令を確認してください。

## ダウンロードして使う

1. GitHubの **Releases** から `X-Space-Recorder-1.1.0-Windows.zip` をダウンロードします。
2. ZIPを右クリックし、**すべて展開**します。
3. `X Space Recorder.exe` を起動します。
4. 初回だけ、画面の **FFmpegを導入** を押します。
5. SpaceのURLを貼り、**録音開始**を押します。

本アプリはコード署名を行っていないため、Windows SmartScreenの警告が出る場合があります。配布元とダウンロード場所を確認して使用してください。

## 主な機能

- ライブ開始時点から現在までの音声を遡って取得
- 取得後もSpace終了まで新しい音声を継続追加
- 終了済みSpaceの公開リプレイを保存
- Spaceタイトルをファイル名に使用
- 同名ファイルを上書きせず連番で保存
- 配信中は5秒ごとに完全履歴を再確認し、スリープや一時切断で欠けたチャンクをその場で自動補完
- Space終了・録音停止時にも最終補完を実行
- 録音中はWindowsの自動スリープを抑止
- Source / M4A / MP3 / WAV / Opusに対応
- 認証なし、またはログイン済みブラウザのCookieを使用

## 保存先

- DドライブがあるPC：`D:\X Space Recorder`
- DドライブがないPC：`ミュージック\X Space Recorder`

アプリ画面から保存先を変更したり、保存フォルダを直接開いたりできます。

保存ファイル名にはSpace名を使用します。同名ファイルがある場合は上書きせず、`Space名 (2).m4a` のように連番を付けます。

## ソースからビルドする

ビルドしてデスクトップへインストールするには次を実行します。

```powershell
.\build-app.ps1 -Install
```

### 保存形式の違い

| 形式 | 特徴 | おすすめ用途 |
| --- | --- | --- |
| Source（推奨・M4A） | Xの元のAAC音声を再エンコードせずM4Aに格納します。音質劣化がなく、保存処理も最速です。 | 通常はこれを選んでください |
| M4A | 現在の実装ではSourceと同じ処理です。 | Sourceと同じ |
| MP3 | 多くの機器やソフトで再生できます。変換時間がかかり、再エンコードによるわずかな音質劣化があります。 | 幅広い環境で共有・再生する場合 |
| WAV | 無圧縮のため編集しやすい一方、容量が非常に大きくなります。元音声より高音質になるわけではありません。 | 音声編集ソフトへ渡す場合 |
| Opus | 小容量で高音質ですが、対応していない再生・編集ソフトがあります。 | 容量を抑えて保管する場合 |

迷った場合は `Source（推奨・M4A）` を選択してください。

### ログイン設定の違い

| 設定 | 内容 |
| --- | --- |
| 認証なし（推奨） | Xへログインせずに取得します。公開Spaceでは、まずこちらを試してください。 |
| Chrome / Edge / Firefox / Brave | 選択したブラウザでXにログイン済みの場合、そのCookieを利用して取得します。ログインが必要なSpaceや、認証なしでは情報を取得できない場合に使用します。 |

アプリへXのIDやパスワードを入力する必要はありません。ブラウザCookieはローカルの `yt-dlp` が読み取り、Xへの取得リクエストにのみ使用します。本アプリがCookieを独自に保存したり、第三者へ送信したりすることはありません。

Cookieの読み取りエラーが表示された場合は、選択したブラウザをバックグラウンド動作も含めて完全に終了し、再試行してください。

### 欠損の自動補完ログ

配信中に未保存チャンクを検知すると、次のように表示してその場で回収します。

```text
欠落を検知: 8チャンクを自動補完します…
自動補完完了: 8チャンクを回収しました
```

すぐに回収できないチャンクは、Spaceが続いている間5秒ごとに再試行します。Space終了または録音停止時には、完全履歴をもう一度確認して「最終補完」を行います。

### CLIのセットアップ

PowerShellでこのフォルダへ移動し、`yt-dlp` とFFmpegを導入します。

```powershell
.\setup.ps1 -InstallFfmpeg
```

すでにFFmpegがPATHに入っている場合だけ、スイッチを省略できます。

```powershell
.\setup.ps1
```

PowerShellの実行ポリシーで止まる場合は、その1回だけ次の形式で実行できます。

```powershell
powershell -ExecutionPolicy Bypass -File .\setup.ps1
```

### CLIで録音

まず認証なしで試せます。

```powershell
.\record.ps1 "https://x.com/i/spaces/SPACE_ID"
```

Xへのログインを要求された場合は、ログイン済みブラウザを指定します。

```powershell
.\record.ps1 "https://x.com/i/spaces/SPACE_ID" --browser chrome
```

Edgeの場合は `--browser edge` です。ブラウザCookieは `yt-dlp` がローカルで読み取り、このツールが保存・送信することはありません。読み取りに失敗する場合はブラウザを完全に終了して再試行してください。

既定では元ストリームの形式を保ち、`recordings` に保存します。X SpaceのHLS取得にはFFmpegが必要です。MP3へ変換する例:

```powershell
.\record.ps1 "https://x.com/i/spaces/SPACE_ID" --browser chrome --format mp3
```

保存先を変える例:

```powershell
.\record.ps1 "https://x.com/i/spaces/SPACE_ID" -o "D:\Space録音"
```

停止は `Ctrl+C` です。通信切断時は自動的に再試行します。X側の仕様変更に追従するには、時々 `setup.ps1` を再実行して `yt-dlp` を更新してください。

## 注意

- ブラウザから聴取できる進行中Space、または公開リプレイのある終了済みSpaceが対象です。
- ホストが録音を残さないSpaceは、終了後に取得できなくなる場合があります。
- PCのふたを閉じた際のスリープは抑止できない場合があります。スリープ中は録音・補完処理も停止するため、録音中はPCのふたを閉じないでください。
- X公式APIはSpaceの情報参照には使えますが、音声ストリーム自体は返しません。本ツールではAPIキーは不要です。
- 録音について参加者への告知、プライバシー、著作権、利用規約、地域の法令を確認し、録音・保存する権限がある場合だけ使用してください。
- Xの仕様変更により一時的に取得できなくなる場合があります。配布版は新しいリリースへ更新してください。ソース版は `setup.ps1` を再実行してyt-dlpを更新できます。

## プライバシー
